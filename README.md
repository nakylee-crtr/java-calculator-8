# java-calculator-precourse

# 문자열 덧셈 계산기

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다

## 기능목록

- [X] 프로그램 시작시 “덧셈할 문자열을 입력해 주세요” 메세지 출력
- [X] 사용자가 구분자와 양수로 구성된 문자열을 입력
- 문자열 처리
    - [x] 빈 문자열 입력시, 숫자 합 = 0
    - [] 형태가 벗어나거나 유효하지 않은 값이 입력되면 IllegalArgumentException 발생 후 애플리케이션 종료
        - [] 벗어난 형태: 기본 구분자, 커스텀 구분자 외의 문자
        - [] 유효하지 않는 값: 음수
    - [] 기본 구분자와 양수로 구성된 문자열 입력시
        - [] 쉼표(,) 또는 콜론(:)을 기준으로 문자열에서 숫자 추출
        - [] 추출한 숫자 합산
    - [] 커스텀 구분자와 양수로 구성된 문자열 입력시
        - [] 문자열 앞부분의 “//”와 “n\” 사이에 위치하는 문자를 커스텀 구분자로 설정
        - [] 커스텀 구분자를 기준으로 문자열에서 숫자 추출
        - [] 추출한 숫자 합산
- [X] “결과: “ + 숫자 합 출력

- [x] 터미널에서 java -version을 실행하여 Java 버전이 21인지 확인한다. Eclipse 또는 IntelliJ IDEA와 같은 IDE에서 Java 21로 실행되는지 확인한다.
- [] 터미널에서 Mac 또는 Linux 사용자의 경우 ./gradlew clean test 명령을 실행하고, Windows 사용자의 경우 gradlew.bat clean test 또는 .\gradlew.bat clean test 명령을 실행할 때 모든 테스트가 아래와 같이 통과하는지 확인한다.
